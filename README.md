## ✨ Secciones

- **Inicio**: presentación y enlaces de contacto.
- **Sobre mí**: experiencia en IA generativa, agentes y automatización.
- **Proyectos destacados**: chatbots y voicebots con LLMs.
- **Habilidades**, **Educación** y **Contacto**.

## 🛠️ Tecnologías

- HTML con [Tailwind CSS](https://tailwindcss.com/) por CDN, con modo oscuro automático.
- Animaciones al hacer *scroll* con [AOS](https://michalsnik.github.io/aos/).
- Despliegue automático a **GitHub Pages** con el flujo [`static.yml`](.github/workflows/static.yml) en cada *push* a `main`.

## 💻 Ver en local

No necesita compilación: abre `index.html` en el navegador o sirve la carpeta.

```bash
python -m http.server 8000
# http://localhost:8000
```
